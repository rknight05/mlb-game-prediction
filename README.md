# mlb-game-prediction
A Python simulation using data and statistical models to predict MLB game outcomes.
* Collects baseball statistics from multiple online sources
* Integrates external API for additional matchup information
* Analyzes team and pitcher performance statistics
* Uses weighted averages to develop projected game scores
* Applies Poisson probability distributions to estimate team win probabilities 

Uses Python, Website Scraping, API Integration, Probability and Statistical Modeling

Disclaimer: The model is experimental and predictions are not guaranteed to be accurate. Results depend on assumptions used in the model.
